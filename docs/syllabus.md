
# 教学大纲

## 课程简介

本课程介绍机器学习的基本概念、典型方法及实际应用。

## 教学目标

通过本课程学习，学生应能够：

1. 理解机器学习的基本概念与基本流程；
2. 掌握常用监督学习和无监督学习方法；
3. 使用 Python 完成数据处理、模型训练与性能评价；
4. 针对实际问题选择合适的机器学习方法。

## 考核方式

具体考核方式将在课程开始后公布。

## 授课安排

| 课次 | 教学主题 | 主要内容 |
| --- | --- | --- |
| 第 1 次课 | 机器学习概述 | 基本概念、学习类型、数据集与模型评价 |
| 第 2 次课 | 线性模型 | 线性回归、逻辑回归与优化基础 |
| 第 3 次课 | 决策树 | 树模型、划分准则与剪枝 |
| 第 4 次课 | 集成学习 | Bagging、Boosting 与随机森林 |
| 第 5 次课 | 支持向量机 | 最大间隔、核方法与软间隔 |
| 第 6 次课 | 神经网络 | 神经元、反向传播与网络训练 |
| 第 7 次课 | 无监督学习 | 聚类与降维 |

> 授课安排可能根据实际教学情况调整。
