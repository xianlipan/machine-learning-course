## 教学目标

通过本课程学习，学生应能够：

1. 理解机器学习的基本概念与基本流程；
2. 掌握常用监督学习和无监督学习方法；
3. 使用 Python 完成数据处理、模型训练与性能评价；
4. 针对实际问题选择合适的机器学习方法。
