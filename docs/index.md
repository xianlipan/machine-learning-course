<div class="home-letter-label"><span aria-hidden="true">✦</span> 课程寄语 <small>A NOTE TO OUR LEARNERS</small></div>

各位同学，欢迎来到《机器学习》课程。
{ .home-paragraph }

其实，机器学习离我们的生活并不远。购物软件猜你喜欢什么，地图帮你规划路线，手机识别照片中的人物和物体，聊天工具生成文字和图片，背后都有机器学习的影子。面对这些看起来很“聪明”的功能，我们不仅要知道它们能做什么，更要进一步理解：它们是怎样从数据中学到规律的？为什么能够完成这些任务？
{ .home-paragraph }

这门课将带大家从数学和数据出发，系统学习机器学习的基本原理与经典方法。我们会沿着“发现数据结构、学习预测规律、理解复杂模型、认识内容生成”的路线，从聚类与降维，到线性回归、逻辑回归、支持向量机、贝叶斯分类、决策树与集成学习，再到神经网络、深度学习和生成模型。在学习这些方法的过程中，我们会不断回到机器学习的基本框架，逐渐看清数据、模型、损失函数、优化算法与评价方法之间的联系，把一个个模型串成一条完整的知识主线。
{ .home-paragraph }

我希望学完这门课以后，大家面对新问题时，知道如何分析和建模；看到公式时，明白它在表达什么；模型效果不理想时，能够一步步找到问题出在哪里。工具会更新，模型会变化，但数学原理、建模逻辑和分析能力不会轻易过时。希望这门课能帮助大家真正读懂模型、用好方法，逐渐形成自己的机器学习思维。
{ .home-paragraph }

欢迎大家一起开始这段从数学出发、走进机器学习与人工智能的学习旅程。
{ .home-paragraph }
