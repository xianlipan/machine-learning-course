# 欢迎来到《机器学习》课程 { .home-title }

各位同学，你们已经进入研究生阶段，接下来会越来越频繁地遇到这样一种场景：面对一份数据、一个现象或一个任务，我们既希望模型“能用、好用”，也希望它“讲得清、推得出、靠得住”。这门课的目标，就是把机器学习中那些经得起时间检验、直到今天仍被广泛使用的核心思想和基本方法，系统地梳理一遍，让它们变成你们手里可反复调用的工具箱。
{ .home-paragraph }

本课程将以“从问题到模型、从模型到算法、从算法到泛化”的主线展开。我们会从最基础的线性回归出发，理解为什么要用损失函数来刻画“学得好不好”，为什么优化问题会自然地导向梯度下降这类迭代算法；再进一步走到逻辑回归等经典分类模型，讨论概率解释与决策边界；同时，我们会反复回到一个贯穿始终的问题：模型在训练集上表现好，为什么在新数据上可能失败？这就引出了过拟合、偏差—方差权衡、正则化与模型选择等关键概念。你们会看到，许多看似“很新”的方法，其实都建立在这些朴素而强大的原则之上。
{ .home-paragraph }

我希望这门课带给你们的不只是“会用某个模型”，而是形成一种稳健的思维方式：面对任务时能做出合理建模假设，面对公式时知道每一项在“惩罚什么、鼓励什么”，面对训练结果时能判断问题出在数据、模型还是优化上。只要把这些基础打牢，你们后续无论做深度学习、统计建模，还是工程落地，都会更快、更稳、更有底气。
{ .home-paragraph }

欢迎大家一起开始这一段系统学习与实践的旅程！
{ .home-paragraph }
